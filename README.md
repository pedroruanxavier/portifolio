## 🎯 Sobre o Projeto

O objetivo deste projeto foi construir uma página web de **Portfólio / Currículo Pessoal** utilizando apenas **HTML5 Semântico**, reproduzindo com fidelidade o layout e os requisitos do modelo proposto.

A página foi construída com foco em boas práticas de estruturação de documentos web, acessibilidade e organização de elementos sem o uso de estilizações complexas.

---

## 🛠️ Tecnologias e Conceitos Aplicados

* **HTML5 Semântico**: Uso das tags estruturais `<header>`, `<nav>`, `<main>`, `<section>`, `<table>`, `<fieldset>` e `<footer>`.
* **Navegação Interna**: Implementação de links de âncora (`href="#id"`) para navegação rápida entre seções.
* **Tabelas Organizadas**: Estruturação de dados dos projetos utilizando `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`.
* **Formulários Acessíveis**: Agrupamento com `<fieldset>` e `<legend>`, além de vínculo explícito entre `<label>` e inputs/textarea.
* **Entidades HTML**: Uso do caractere especial `&copy;` no rodapé.

---

## 📋 Requisitos do Desafio Atendidos

- [x] **Cabeçalho e Navegação:** Nome/cargo no título e menu com links para *Sobre*, *Projetos* e *Contato*.
- [x] **Seção "Sobre Mim":** Foto de perfil dimensionada em `150x150px`, texto de apresentação e lista de habilidades.
- [x] **Seção "Meus Projetos":** Tabela de 4 colunas (*Projeto*, *Tecnologias*, *Status*, *Link*) com hiperlinks funcionais.
- [x] **Seção "Entre em Contato":** Formulário agrupado por `<fieldset>` ("Dados do Contato"), com campos para Nome, E-mail, menu suspenso (`<select>`) para Assunto, área de texto (`<textarea>`) e botão de envio.
- [x] **Rodapé (`<footer>`):** Copyright com `&copy;`, além de e-mail e telefone de contato informados.

## 🚀 Como Executar o Projeto

1. Clone ou baixe este repositório para o seu computador.

3. Abra o arquivo `portifolio.html` diretamente no seu navegador ou utilize a extensão **Live Server** para rodar no endereço local (ex: `http://127.0.0.1:5500/portifolio/portifolio.html`).
